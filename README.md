# distance-calculator-

## This calculates the distance between two points

## How to run
1. Open the program.
2. Run the program.
3. Enter the required value.

## Input Needed
1. Enter x1
2. Enter y1
3. Enter x2
4. Enter y2

## Sample Output
 Enter x1: 3
 Enter y1: 5
 Enter x2: 4
 Enter y2: 2
 The distance between the two points is 3.16
